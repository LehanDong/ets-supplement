# Anonymous Supplement

This compact package contains only the materials required to inspect the empirical claims in the paper.

## Contents

- `data/stimuli/`: deidentified stimuli for the diagnostic, paired, bridge-strength, and counterbalanced studies.
- `data/outcomes/`: row-level model outcomes for the four controlled studies.
- `data/summary/`: tables supporting the reported component distribution, paired effects, bridge-response profile, response-model comparison, robustness checks, manipulation check, and human-reference comparison.
- `scripts/`: analysis scripts used for the principal and robustness analyses.


## Sample accounting

The package contains 66 diagnostic stimuli with 132 responses, 150 paired-validation stimuli with 450 responses, 150 bridge-strength stimuli with 450 responses, and 60 counterbalanced stimuli with 180 responses. Anonymous identifiers are package-local and cannot be mapped back to source judgments from the released files.
